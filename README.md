# Mente activa

Aplicación web sencilla con actividades de estimulación cognitiva: cálculo, lógica, memoria, atención, lenguaje y conversación.

Pensada para usarse en una tablet, con letra grande, sin cronómetros y con refuerzo siempre positivo.

## Actividades

- **Cálculo:** sumas, restas, dar el cambio, la compra
- **Lógica:** series de números, el intruso, rutinas
- **Memoria:** parejas, repetir la secuencia, recordar palabras
- **Atención:** el dibujo diferente, ¿qué día es hoy?
- **Lenguaje:** refranes, letras desordenadas, sopa de letras
- **Charlar:** preguntas para conversar y fotos personales

También incluye una sesión diaria de 3 actividades, niveles de dificultad adaptables, lectura en voz alta, tamaño de letra ajustable, progreso semanal y copia de seguridad.

## Uso

Es un único archivo (`index.html`) sin dependencias. Se puede abrir directamente en el navegador o publicar con GitHub Pages.

Los datos (progreso, ajustes y fotos) se guardan solo en el navegador del dispositivo.

## Aviso

Son ejercicios de estimulación para el día a día. No sustituyen la valoración de un médico o neuropsicólogo.
